## 🚀 当前项目

### [TopFlow](https://github.com/csupenn/topflow)（开发中）
面向**安全 AI 应用**的开源可视化工作流构建器。

**特性：**
- 12 种 AI 编排节点类型
- 安全导向模板（GDPR、ISO 27001、SOC 2、HIPAA）
- 内置安全防护：SSRF 防护、限流、循环检测
- 隐私优先架构（仅使用 localStorage）
- 一键导出 TypeScript 代码
